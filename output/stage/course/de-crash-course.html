    Section A Crash Course in Concentration Models

    Many quantities in biology and medicine change continuously over time. Understanding how different government policies or administrative decisions affect these quantities requires a way to model their dynamics. For example, we might want to understand how hormone levels change during treatment, or how they respond to changes in dosing schedules.
    🔗
    Differential equations provide a way to model how these quantities evolve. In this section, we review the key ideas needed to study concentration decay, repeated dosing, and interacting systems.
    🔗

    Subsection Exponential Decay

    A common assumption is that a substance leaves the body at a rate proportional to how much is present. If \(H(t)\) represents a concentration, this leads to the differential equation
    🔗
    \begin{equation*} \frac{dH}{dt} = -kH, \quad k > 0. \end{equation*}
    The solution with initial condition \(H(0)=H_0\) is
    🔗
    \begin{equation*} H(t) = H_0 e^{-kt}. \end{equation*}
    This function decreases over time and approaches \(0\) as \(t \to \infty\text{.}\)
    🔗
    The half-life of a substance is the time required for the concentration to be cut in half. If the half-life is \(T_{1/2}\text{,}\) then
    🔗
    \begin{equation*} k = \frac{\ln 2}{T_{1/2}}. \end{equation*}
    🔗

    Subsection Equilibrium and Constant Input

    If a constant input \(u\) is added, the model becomes
    🔗
    \begin{equation*} \frac{dH}{dt} = -kH + u. \end{equation*}
    This equation has an equilibrium value \(H^\ast\text{,}\) where the concentration no longer changes:
    🔗
    \begin{equation*} H^\ast = \frac{u}{k}. \end{equation*}
    The solution can be written as
    🔗
    \begin{equation*} H(t) = H^\ast + (H_0 - H^\ast)e^{-kt}. \end{equation*}
    This shows that the concentration moves toward the equilibrium exponentially over time.
    🔗
    🔗

    Subsection Repeated Dosing

    When doses are taken at regular intervals, it is often useful to model the concentration just after each dose. If a fraction \(a\) of the concentration remains between doses and each dose adds \(D\text{,}\) then
    🔗
    \begin{equation*} H_{n+1} = aH_n + D. \end{equation*}
    This recurrence has a steady state
    🔗
    \begin{equation*} H^\ast = \frac{D}{1-a}, \quad \text{when } 0 < a < 1. \end{equation*}
    The sequence \(H_n\) approaches this value as \(n\) increases.
    🔗
    🔗

    Subsection Interacting Quantities and Linear Systems

    Many systems involve multiple interacting quantities. For example, one concentration may influence the production or suppression of another.
    🔗
    A simple model with two variables can be written as
    🔗
    \begin{equation*} \mathbf{x}' = A\mathbf{x} + \mathbf{r}, \end{equation*}
    where
    🔗
    \begin{equation*} \mathbf{x} = \begin{pmatrix} x_1 \\ x_2 \end{pmatrix}. \end{equation*}
    The matrix \(A\) describes how the variables interact, and the vector \(\mathbf{r}\) represents external inputs.
    🔗
    An equilibrium point satisfies
    🔗
    \begin{equation*} A\mathbf{x} + \mathbf{r} = \mathbf{0}. \end{equation*}
    The behavior of the system near equilibrium is determined by the eigenvalues of \(A\text{:}\)
    🔗
    • If all eigenvalues are negative, solutions move toward equilibrium (stable behavior).
      🔗
    • If any eigenvalue is positive, solutions move away from equilibrium (unstable behavior).
      🔗
    🔗

    Subsection The Big Picture

    Across these models, a few key ideas repeat:
    🔗
    • Exponential functions describe how concentrations change over time.
      🔗
    • Equilibria represent long-term behavior.
      🔗
    • Rates of change determine how quickly systems move toward equilibrium.
      🔗
    • Interactions between variables can be studied using matrices and eigenvalues.
      🔗
    These tools allow us to move between equations, graphs, and systems, and to understand how changes in parameters affect behavior over time.
